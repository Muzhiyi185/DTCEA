# DTCEA
This repository provides the MATLAB implementation of **DTCEA**, a dynamic constraint-Pareto dominance guided two-stage co-evolutionary algorithm for constrained multi-objective optimization.
The code is designed to run directly on the [PlatEMO](https://github.com/BIMK/PlatEMO) platform. The implementation corresponds to the algorithm described in:
> Qihong Chen, Qingsong Zhao, Zhigang Zou, and Renpeng Yuan, “A dynamic constraint-Pareto dominance guided two-stage co-evolutionary algorithm for constrained multi-objective optimization.”
